# Анализ LearnFlow

## Продуктовая задача

LearnFlow — приложение для изучения языков. Команда проверяет идею: после диагностики показать новому пользователю персональную рекомендацию первого урока вместо обычного каталога.

Эксперимент `first_lesson_recommendation_v2` уже подготовлен:

- control видит обычный каталог
- test видит персональную рекомендацию после диагностики.

Ваша задача — проверить, как варианты связаны с завершением первого урока, и отдельно оценить ранние отмены пробного периода. Наблюдаемая разница не считается доказанным причинным эффектом без достаточного объёма и критерия неопределённости.

## Маршрут работы

1. Сформулируйте продуктовый вопрос и исходную гипотезу.
2. Прочитайте `AGENTS.md`, исследования, журнал гипотез и `data/schema.md`.
3. Зафиксируйте определения в `SPEC.md`.
4. Получите план SQL через IDE-агента и проверьте его по схеме.
5. Проверьте воронку, эксперимент, защитную метрику, один сегмент и качество данных.
6. После собственной попытки сопоставьте результат с `results/control-values.md`.
7. Зафиксируйте факт, гипотезу, альтернативное объяснение, ограничение и своё решение в `analysis-notes.md`.

## Границы работы

- Используйте только файлы этого проекта.
- Выполняйте только читающие SQL-запросы.
- Не меняйте `SPEC.md` без собственного решения и не позволяйте агенту менять её без подтверждения.
- Не добавляйте новые обязательные файлы, новую воронку, новый эксперимент или второй сегмент.
