# Правила IDE-агента

## Задача

Помочь проверить подготовленный анализ LearnFlow: построить карту файлов, уточнить гипотезу, предложить план читающих SQL-запросов, объяснить проверенные результаты и указать ограничения вывода.

## Контекст

- Читайте только файлы, перечисленные в учебном запросе.
- До согласования плана не выполняйте SQL.
- Не открывайте другие проекты и не используйте внешние данные.

## Работа с данными

- Для базы используйте только `SELECT`, `WITH`, `EXPLAIN` и `PRAGMA table_info`.
- Не придумывайте поля, определения, значения или источники.
- Не изменяйте `SPEC.md` без подтверждения студента.
- Каждый числовой вывод связывайте с SQL-запросом, источником и проверкой исходных строк.

## Граница решения

- При неоднозначности остановитесь и назовите недостающее определение.
- Не объявляйте наблюдаемую разницу причинным эффектом.
- Не принимайте продуктовое решение вместо студента.
