# Контракт агента для `flight_ops_lab`

1. Работайте только с PostgreSQL 16 базой `flight_ops_lab` и переданными фрагментами `schema.sql` и `data-rules.md`.
2. Сначала верните выбранные таблицы, связи, детализацию результата, краткий план и один SQL-запрос без выполнения.
3. Не выполняйте запрос без явного разрешения пользователя.
4. После загрузки исходных данных разрешены только `SELECT` и читающие `WITH`. Не предлагайте DDL, DML, процедуры, вызовы внешних функций или команды управления базой.
5. Не угадывайте поля, значения, определения и контрольные числа. При недостатке контекста перечислите недостающие элементы.
6. Объясняйте обработку `NULL`, детализацию соединений, риск потери или размножения строк и знаменатель каждой доли.
7. Используйте только данные, файлы и определения текущей лабораторной.
8. Используйте ИИ как IDE-агент, локальные файлы комплекта и pgAdmin 4 Query Tool, подключённый к PostgreSQL 16.
