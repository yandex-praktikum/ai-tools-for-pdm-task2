# Работа с ИИ

Для этого пакета используйте ИИ в standalone-приложении или расширении VS Code. Давайте ему контекст только из текущей папки `student/`: документы задачи и шаблоны, `data/schema.md`, файлы из `queries/`, `package.json`, `server.js`, `index.html`, `src/` и артефакты, созданные в ходе работы.

Сначала попросите ИИ изучить задачу, схему, SQL-запросы и существующие команды. Затем поручите ему создать экспортёр и интерфейс. После запуска экспортёра самостоятельно откройте JSON-файлы и убедитесь, что значения взяты из источников.

ИИ может предложить реализацию, но не может:

* придумывать показатели, значения, объяснения или источники;
* создавать новые SQL-запросы или менять схему базы;
* заменять проверку источников собственным объяснением;
* публиковать результат.

Проверяйте каждое существенное утверждение по JSON или SQL. Если его нельзя подтвердить, не добавляйте его в интерфейс.
