# Аудитория решения

Решение предназначено для руководителя городских операций CityRide и менеджера RidePass. Им нужно выбрать следующий шаг по расширению подписки, сохранив видимость спроса, использования и операционного риска.

Им не нужен отчёт обо всех метриках CityRide. Каждый блок должен отвечать на часть вопроса о Riverside и Northside и позволять проверить утверждение по выданному источнику.
