# Схема выданного набора

База `cityride.sqlite` содержит четыре таблицы. Они предназначены для сверки уже выданных результатов, а не для создания новых запросов.

| Таблица | Назначение |
| --- | --- |
| `subscription_funnel` | Количество пользователей на стадиях подписки |
| `weekly_rides` | Недельное число поездок RidePass и разовых поездок |
| `district_performance` | Использование и конверсия по районам |
| `district_operations` | Операционные защитные метрики по районам |

Файлы в `queries/` фиксируют проверенные выборки. Их результаты вы создадите самостоятельно в `exports/` с помощью `scripts/export-data.mjs`.

Защитная метрика этого задания — поле `cancellation_rate_pct` из `district_operations`. Поля об инцидентах и завершённых поездках остаются в результате экспорта как контекст источника, но не заменяют заданную защитную метрику и не требуют новой аналитики.
