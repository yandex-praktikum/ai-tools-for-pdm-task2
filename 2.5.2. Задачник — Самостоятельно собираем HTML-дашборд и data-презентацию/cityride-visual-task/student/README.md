# CityRide: стартовый проект

CityRide рассматривает расширение RidePass на два новых района. Этот пакет содержит только разрешённый контекст и стартовый проект. Готового дашборда, data-презентации и итогового промпта в нём нет.

Основной IDE-инструмент для этого пакета — **ИИ** в standalone-приложении или расширении VS Code. Используйте один из этих интерфейсов ИИ на протяжении всей работы.

## Запуск

Требуется Node.js 22.

```bash
node --version
npm --version
npm install
```

После того как вы создадите `scripts/export-data.mjs`, получите данные командой:

```bash
npm run data:export
```

Затем запустите интерфейс:

```bash
npm run start
```

Откройте адрес, который выведет команда. По умолчанию это `http://localhost:4173`.

Сохраните оба режима в `index.html`:

* дашборд — `http://localhost:4173/#dashboard`
* data-презентация — `http://localhost:4173/#presentation`.

## Что изучить перед началом

Перед работой прочитайте `task.md`, `AGENTS.md`, `audience-brief.md` и `data/schema.md`. Для экспорта используйте `data/cityride.sqlite` и четыре файла в `queries/`.

Готовых JSON-файлов в стартере нет: их создаёт ваш экспортёр в `exports/`. Защитная метрика этого пакета — уровень отмен. Эталонные скриншоты для итоговой сверки находятся в конце урока.

Сохраняйте локальные рабочие артефакты в этой папке. Внешняя сдача не требуется.
