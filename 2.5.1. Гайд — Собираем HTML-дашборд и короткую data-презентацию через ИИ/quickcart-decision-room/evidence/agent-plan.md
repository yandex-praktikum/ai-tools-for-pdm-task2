# План четырёх блоков ИИ

ИИ прочитал только разрешённые файлы проекта и до изменения интерфейса зафиксировал план.

| Блок | Показатель / сущность | SQL | JSON | Визуальная роль | Проверка |
|---|---|---|---|---|---|
| Ключевой показатель | Доля завершённых доставок вовремя в июне | `queries/01-key-metric.sql` | `exports/key-metric.json` | Горизонтальная шкала 0–100% с порогом | 250/270 = 92,6%; порог 90,0% |
| Динамика | Доля доставок вовремя по месяцам | `queries/02-monthly-trend.sql` | `exports/monthly-trend.json` | Линия с подписями значений | Шесть месяцев в порядке SQL, без причинного вывода |
| Сегменты | Доля по двум районам в июне | `queries/03-district-comparison.sql` | `exports/district-comparison.json` | Две подписанные полосы 0–100% | 137/145 и 113/125; одинаковый знаменатель |
| Ограничение | Наличие доказательств для решения | `queries/04-decision-limit.sql` | `exports/decision-limit.json` | Категории «проверено» / «нет в данных» | Не присваивать отсутствующим данным числовое значение |

Разрывов файлового маршрута не найдено. Код меняется только после прохождения `npm run data:verify`.
