# Правила для IDE-агента

## Задача

Поддерживать локальный проект QuickCart, не расширяя аналитический scope.

## Разрешённый контекст

* `README.md`
* `SPEC.md`
* `audience-brief.md`
* `design-spec.md`
* `evidence-manifest.md`
* `data/`
* `queries/`
* `exports/`
* `src/`
* `scripts/`
* `smoke-checklist.md`

## Ограничения

1. Не создавать новые показатели, районы, периоды или SQL-запросы.
2. Не изменять схему и synthetic snapshot без отдельной production-проверки.
3. Не вводить продуктовые значения вручную в `src/`; интерфейс читает JSON из `exports/`.
4. Не добавлять библиотеку визуализации кроме Apache ECharts.
5. Инициализировать каждый график с `{ renderer: 'svg' }` и отключать декоративную анимацию.
6. Не превращать наблюдаемую динамику в причинный вывод.
7. Не обещать постоянное расширение: в данных нет прогноза курьерской ёмкости и экономики после роста объёма.

## Порядок работы

1. Назвать один изменяемый блок и его SQL/JSON.
2. Воспроизвести экспорт командой `npm run data:export -- <export-id>`.
3. Сверить строки SQL и JSON командой `npm run data:verify`.
4. Изменить один визуальный компонент или экран.
5. Выполнить `npm run verify` и browser smoke-check.
6. При расхождении остановиться и перечислить его, не подставляя предполагаемое значение.
