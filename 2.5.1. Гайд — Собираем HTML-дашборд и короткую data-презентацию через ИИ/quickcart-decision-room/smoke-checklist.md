# Smoke-чек-лист

## Окружение

- [x] Node.js `v22.18.0` и npm `10.9.3` зафиксированы.
- [x] `npm ci` использует один `package-lock.json`.
- [x] `npm list echarts` показывает `echarts@6.1.0`.
- [x] `npm run verify` проходит на Windows.
- [x] `npm run browser:smoke` после чистого `npm ci` запускает SQL-проверку и desktop/mobile browser-check.
- [x] `npm run dev` открывает `http://localhost:4173/`.

## Источники

- [x] Четыре SQL выполняются на `data/quickcart.sqlite`.
- [x] Четыре JSON побайтово воспроизводимы при повторном экспорте.
- [x] Значения, подписи, единицы и порядок совпадают.
- [x] Пустые или отсутствующие доказательства обозначены явно.

## Интерфейс

- [x] Четыре блока отображаются в обзорном режиме.
- [x] Data-презентация содержит четыре экрана 16:9.
- [x] Оба режима используют одни JSON и функции конфигурации ECharts.
- [x] Каждый график отрисован как SVG.
- [x] Кнопки режимов и навигации работают.
- [x] На desktop и mobile нет пустых блоков, обрезанного или перекрывающегося текста.
- [x] В консоли браузера нет ошибок.

## Решение

- [x] Рекомендация отвечает на один вопрос QuickCart.
- [x] Ограничение видно в обоих режимах.
- [x] Порог, вопрос и решение читаются из проверенных JSON/metadata; mismatch останавливает загрузку.
- [x] В интерфейсе нет новой аналитики, ручных продуктовых значений или второй библиотеки визуализации.
