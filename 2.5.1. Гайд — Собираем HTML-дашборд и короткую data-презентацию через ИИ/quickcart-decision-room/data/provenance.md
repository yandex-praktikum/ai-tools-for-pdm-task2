# Происхождение synthetic snapshot

`quickcart-evening-pilot-v1` создан production-скриптом `scripts/create-database.mjs` для проекта QuickCart Decision Room. Набор не содержит реальных пользователей, заказов, адресов или рабочих данных.

Скрипт детерминированно создаёт 1470 завершённых заказов вечернего пилота за январь–июнь 2026 года. Количество заказов и доставок вовремя задано в открытом плане генерации; фактическое время доставки вычисляется по фиксированной формуле. Повторный запуск на зафиксированной версии Node.js создаёт ту же логическую базу и те же четыре JSON-экспорта.

Контрольные значения:

* июнь: 270 завершённых заказов, 250 вовремя, `92,6%`
* Северный район в июне: 145 заказов, 137 вовремя, `94,5%`
* Восточный район в июне: 125 заказов, 113 вовремя, `90,4%`
* январь–июнь: `87,3%`, `89,1%`, `91,3%`, `91,6%`, `92,3%`, `92,6%`.

SHA-256 текущей базы записывается в каждый JSON при экспорте и проверяется командой `npm run data:verify`.
