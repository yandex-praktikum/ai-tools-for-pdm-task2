# Юнит-экономика FitFlow: готовый учебный проект

Это заполненный и воспроизводимый проект для урока 2.4.1. Мы используем его
как пример полного пути от продуктового вопроса к проверенному решению.

Сравниваем `paid_social` и `partners` за период привлечения с `2025-01-01`
по `2025-01-31` и горизонт наблюдения до `2025-06-30`.

## Что уже заполнено

* `SPEC.md` фиксирует аналитический контракт.
* `formulas.md` содержит формулы, переменные и точные источники.
* `queries/01_source_aggregates.sql` — проверенный читающий запрос.
* `analysis-notes.md` документирует проверку расчёта и ограниченную
  рекомендацию.
* `results/unit-economics.csv` создан исполняемым расчётом, а не вручную.

В гайде мы открываем эти файлы, прослеживаем связь между ними, запускаем
сохранённый запрос и повторяем расчёт. Ничего из итоговой таблицы не меняем
вручную.

## Просмотр базы

Откроем `data/fitflow.sqlite` в отдельно установленной ранее программе
`DB Browser for SQLite`. В ней смотрим таблицы и строки исходных данных, а
также выполняем `queries/01_source_aggregates.sql` только для чтения.

## Повторный запуск расчёта

Используем Node.js `24.18.0`, установленный ранее в курсе. Из этой директории
проекта выполним:

```powershell
node calculations/calculate.mjs
```

Команда заново создаёт `results/unit-economics.csv` с двумя контрольными
строками. Отдельно устанавливать `npm`-пакеты или SQLite-драйвер не нужно:
`calculate.mjs` использует встроенный модуль Node.js `node:sqlite`.
