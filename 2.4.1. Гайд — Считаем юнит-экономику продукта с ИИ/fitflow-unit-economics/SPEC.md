# Аналитическая спецификация FitFlow

* Продуктовый вопрос: какой из `paid_social` и `partners` должен получить
  ограниченный тест привлечения на основе проверенной шестимесячной экономики?
* Период привлечения: с `2025-01-01` по `2025-01-31` включительно.
* Горизонт наблюдения: с `2025-01-01` по `2025-06-30` включительно.
* Единица сравнения: канал привлечения.
* Новый клиент: зарегистрированный клиент в периоде привлечения.
* Новый платящий клиент: уникальный клиент, чья первая успешная оплата попала
  в период привлечения.
* Возврат: сумма, связанная с платежом когорты и проведённая в горизонте
  наблюдения; она один раз уменьшает валовую выручку.
* Правило: сравнить оба канала по шести обязательным метрикам и их исходным
  агрегатам, затем назвать действие и условие либо риск.
* Отсутствующие данные: остановить расчёт затронутой метрики; не приводить
  неизвестные значения к нулю.
