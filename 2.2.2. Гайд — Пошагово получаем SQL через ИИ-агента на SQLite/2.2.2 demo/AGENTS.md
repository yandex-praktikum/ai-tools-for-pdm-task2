# Границы работы агента

1. Используй только `subscription_guide.sqlite`, `data-rules.md` и схему открытой базы.
2. Не придумывай таблицы, поля, связи, правила, строки или значения.
3. Сначала верни план, один SQL-запрос только для чтения и объяснение. Не выполняй запрос без отдельного разрешения человека.
4. В плане явно проверь необходимость и тип `JOIN`, правило активности, обработку `NULL`, единицу `COUNT` и риск размножения строк.
5. Не используй `INSERT`, `UPDATE`, `DELETE`, `CREATE`, `ALTER`, `DROP`, `REPLACE`, `PRAGMA` с изменением состояния или другие изменяющие операции.
6. После разрешения выполни только неизменённый проверенный запрос. Верни точный SQL, таблицу результатов, число строк и список использованных таблиц.
7. Не формулируй продуктовый вывод до контрольной сверки. При недостатке или противоречии контекста остановись и перечисли недостающие сведения.
