# TeamSpace experiment

Этот комплект содержит материалы самостоятельного кейса TeamSpace. Он не содержит готовых SQL-запросов, контрольных значений или допустимого решения.

## Состав комплекта

* `AGENTS.md` — разрешённый контекст и ограничения для IDE-агента
* `task.md` — рабочий запрос руководителя
* `SPEC.md` — черновик спецификации анализа
* `data/teamspace.sqlite` — синтетическая база TeamSpace
* `data/schema.md` — схема и словарь полей
* `research/interview-summary.md` — исследовательский контекст
* `hypotheses/hypothesis-log.md` — исходные гипотезы команды
* `analysis-notes.md` — шаблон анализа, карты доказательств и следа применения ИИ
* `decision.md` — шаблон решения и защиты

## Порядок работы

1. Сначала прочитайте `AGENTS.md`, `task.md`, черновой `SPEC.md`, схему, исследование и журнал гипотез.
2. Дополните `SPEC.md`, не заменяя неизвестные данные догадками.
3. Получите SQL через поддерживаемого курсом IDE-агента, проверьте каждый запрос и сохраните его.
4. Заполните `analysis-notes.md`, затем примите решение в `decision.md`.
5. Сохраните собственные запросы, расчёты и решение.

Все запросы к базе должны быть читающими. Не изменяйте `data/teamspace.sqlite` и не передавайте агенту файлы за пределами списка в `AGENTS.md`.

## Рекомендуемый маршрут

* Уточните контекст и дополните `SPEC.md`.
* Проверьте качество данных и соберите SQL-доказательства по воронке.
* Рассчитайте основную и защитную метрики, а также результат в разрезе размера команды.
* Проверьте возражения ИИ, соберите карту доказательств и сформулируйте решение.
* Выполните финальную самопроверку результатов и разберите расхождения.

Сохраняйте проверяемую цепочку «вопрос → SQL → результат → ограничение» для обязательных пяти блоков анализа. Не расширяйте кейс новыми сегментами, статистическими тестами или дополнительными визуализациями.
