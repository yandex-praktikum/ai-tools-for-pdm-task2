# Правила для IDE-агента

## Разрешённый контекст

Агенту можно читать только:

* `README.md`
* `AGENTS.md`
* `task.md`
* `SPEC.md`
* `data/schema.md`
* `data/teamspace.sqlite`
* `research/interview-summary.md`
* `hypotheses/hypothesis-log.md`
* текущие версии `analysis-notes.md`, `decision.md` и файлов в `queries/`

## Ограничения

* Получайте только читающие SQL-запросы: `SELECT` или `WITH ... SELECT`.
* Не изменяйте базу, схему и исходные материалы кейса.
* Не выдумывайте таблицы, поля, значения, определения метрик и факты исследования.
* Отмечайте неизвестное как открытый вопрос.
* Для каждого SQL-запроса объясняйте единицу результата, соединения, фильтры и способ проверки.
* Не принимайте продуктовое решение за студента.

Каждая задача агенту должна включать контекст, конкретную задачу, формат результата, ограничения и способ проверки.
