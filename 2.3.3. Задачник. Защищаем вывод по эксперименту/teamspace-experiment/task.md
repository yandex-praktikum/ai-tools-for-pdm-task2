# Рабочий запрос руководителя

Команда TeamSpace проверяет эксперимент `guided_project_template_v1`. Контрольная группа после онбординга получает пустое рабочее пространство, тестовая — готовый шаблон проекта.

Нужно определить:

* повышает ли вариант семидневную активацию в доступной выборке
* на каком этапе воронки возникает различие
* сохраняется ли вывод после проверки качества данных
* что происходит с защитной метрикой и разрезом по размеру команды
* следует ли запустить вариант, остановить его или повторить эксперимент

Решение должно опираться на воспроизводимые читающие SQL-запросы и явно отделять факт, интерпретацию, альтернативное объяснение, ограничение и рекомендацию.
