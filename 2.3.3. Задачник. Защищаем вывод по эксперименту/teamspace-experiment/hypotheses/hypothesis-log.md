# Исходные гипотезы команды

| ID | Гипотеза | Статус до анализа |
|---|---|---|
| H1 | Готовый шаблон повышает долю рабочих пространств с первой завершённой задачей за семь дней. | Требует проверки. |
| H2 | Основное различие возникает между созданием первой задачи и её завершением. | Требует проверки по воронке. |
| H3 | Эффект сильнее у небольших команд. | Требует сегментной проверки. |
| H4 | Шаблон может ухудшить защитную метрику из-за раннего удаления пространства или отмены пробного периода. | Требует проверки. |

Записи являются предположениями команды. Не используйте их как факты без SQL-доказательств.
