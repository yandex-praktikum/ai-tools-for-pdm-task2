# Определения метрик OrbitDesk

## Общие правила

* Часовой пояс: UTC.
* Месячные периоды полуоткрытые: начало месяца включается, начало следующего месяца не включается.
* Единица наблюдения продуктовых метрик: уникальный `account_id`, если явно не указано иное.
* Повторные события и несколько интеграций одного аккаунта не создают новые аккаунты в знаменателе.

## Аккаунт продуктового знаменателя

Аккаунт входит в знаменатель месяца, если:

* `created_at` попадает в месяц когорты
* `is_internal = 0`
* `canceled_within_24h = 0`

## Активация за семь дней

Аккаунт активирован, если для него существует событие `workspace_activated` не раньше `created_at` и не позднее чем через семь суток после создания.

Доля активации:

`число уникальных активированных аккаунтов / число уникальных аккаунтов продуктового знаменателя`.

## Группа с интеграцией

Аккаунт относится к группе с интеграцией, если в первые семь суток после `created_at` у него есть хотя бы одна строка в `integrations`. Для сравнения групп каждый аккаунт учитывается один раз независимо от числа интеграций.

## Время до активации

Время до активации — число часов от `created_at` до первого события `workspace_activated` в семидневном окне. Медиана считается отдельно по месяцу создания аккаунта и только среди активированных аккаунтов продуктового знаменателя.

## Полнота роли владельца

Полнота роли владельца среди активированных аккаунтов:

`число активированных аккаунтов с непустым owner_role / число активированных аккаунтов`.

`NULL` и строка из пробелов считаются отсутствующим значением.

## CAC канала

CAC канала:

`расходы на привлечение канала за период / число аккаунтов продуктового знаменателя из этого канала за тот же период`.

Для проверки нужны оба источника за совпадающие период и канал. Количество аккаунтов без расходов не позволяет вычислить CAC.
